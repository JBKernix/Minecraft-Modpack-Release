# Minecraft-Modpack-Release
Minecraft 1.20.1 / Forge 47.4.28 Packwiz distribution.

Packwiz manifest: [pack.toml](https://raw.githubusercontent.com/JBKernix/Minecraft-Modpack-Release/main/pack.toml)

### Crabber's Delight recipe fix

The pack includes `crabbers-lanternfish-fix.zip` in the instance's `datapacks` folder. For a new single-player world, add the ZIP using **Data Packs** when creating the world. For an existing world or a dedicated server, copy the ZIP into that world's `datapacks` folder and enable it with `/datapack enable "file/crabbers-lanternfish-fix.zip" last`, or enable it through the new-world menu. The fix only disables the two optional lanternfish barrel recipes.
